      01

      IP Address Intelligence

      PUBLIC IP DATA

      Введи публичный IPv4 или IPv6 адрес, чтобы получить ориентировочную информацию о сети и регионе.

      Запрашиваем сведения об IP
      IP ADDRESS

      IP-запрос передаётся сервису ipwho.is. Результат приблизительный и обычно указывает на сеть/узел провайдера, а не точное положение устройства. Частные и локальные IP блокируются.

      04

      Подключение ИИ

      GEMINI API

      Чтобы AI GeoFinder мог анализировать фотографии, подключи Google Gemini. Это делается один раз — ключ сохранится на твоём компьютере.

      01

      Открой Google AI Studio

      Перейди на официальный сайт Google, где создаются ключи доступа к Gemini.

      Открыть Google AI Studio ↗
      02

      Создай API-ключ

      Войди в Google-аккаунт, нажми Create API key и выбери проект Google Cloud, если сайт попросит. Скопируй созданный ключ.

      03

      Вставь ключ сюда

      Вернись в AI GeoFinder и вставь скопированный ключ в поле ниже. Нажми «Сохранить ключ».

      Проверяем настройки…
      Что будет дальше?

      После сохранения вернись во вкладку «Фотоанализ», загрузи фотографию и нажми «Анализировать фото». Программа отправит изображение в Gemini для поиска общих географических признаков.

      Важно: ключ хранится в файле .env рядом с программой. Не отправляй его другим людям и не публикуй на GitHub. Google может устанавливать квоты и условия оплаты для API.
